# 5. Critical Vulnerabilities & Recommendations

1. **P0 — Publish only completed, internally consistent forecast batches.** An induced failure after row 3 and an issuance crossing the 60-second limit must preserve audit history while exposing no partial new batch. The dashboard and scheduled brief must agree on the same batch and last successful issuance. An expired prior batch should yield an explicit abstention.
2. **P0 — Separate model evidence from graphical interpolation.** Fix duplicate-index expansion and preserve projected dates as dates. Show independent event and calendar estimates, each with its tier and origin. Draw a single interval as a whisker. Add a regression check for four unique dated targets and no shading for Tier 4 or for a single bounded target.
3. **P0 — Enforce use and uncertainty policy at issuance and display.** Keep Tier 1 disabled pending independent approval. Put the research designation and active data limitation beside the point estimate. Require tier-specific, finite, ordered and sufficiently supported intervals and probabilities. Test malformed rows, stale markets, date expiry, same-day unknown announcements, and unsupported regimes. Withhold numeric Tier 2 probabilities from the primary decision view until calibration is demonstrated on distinct prospective outcomes.
4. **P1 — Build an evidence-grade target and pricing input register.** Obtain original Ministry decisions with publication and effective clocks, adjudicate gaps and revisions, and collect entitled Mediterranean assessments and dated fiscal/FX inputs. Separate source freshness, source publication latency and historical data revision status. Evaluate proxy basis and window assumptions against an untouched or pre-registered prospective sample before training changes. Retain simple benchmarks and use verified loss improvements to justify complexity.
5. **P1 — Reconcile metrics, settlement and baseline versions.** Link every displayed performance metric to its exact live method, threshold, time window and run. Validate the baseline eligibility rule on the same origins as candidate models. Use both exact direction and the documented tolerance metric with unambiguous labels. Treat unreviewed target coverage as pending in prospective scorecards.
